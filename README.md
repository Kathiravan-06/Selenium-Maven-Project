# Selenium Maven Project

## About
This project demonstrates browser automation using Selenium WebDriver with Java and Maven.

## Technologies Used
- Java
- Selenium WebDriver
- Maven
- JUnit
- Google Chrome

## Project Structure
```text
selenium_maven_project/
├── src/
│   ├── main/
│   │   └── java/com/selenium/App.java
│   └── test/
│       └── java/com/selenium/AppTest.java
├── pom.xml
└── .gitignore
```

## How to Run

1. Install Java and Maven.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
mvn clean compile exec:java -Dexec.mainClass="com.selenium.App"
```

## Purpose
To learn and practice Selenium automation using a Java Maven project.
